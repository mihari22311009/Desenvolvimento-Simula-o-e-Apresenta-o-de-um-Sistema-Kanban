# Sistema Kanban para Gestão de Reservas de Pousada

Projeto desenvolvido na disciplina de **Metodologias Ágeis**, com o objetivo de aplicar os conceitos e práticas do **Kanban** na organização do fluxo de trabalho de uma equipe de desenvolvimento.

## Sobre o projeto

O projeto simula o desenvolvimento e a manutenção de um **sistema web de reservas para uma pousada**, responsável por gerenciar a disponibilidade de quartos, reservas, check-in, check-out e cancelamentos.

O Kanban foi utilizado para representar o fluxo de trabalho da equipe, desde o recebimento de uma demanda até sua entrega e validação.

## Fluxo Kanban

O quadro foi organizado nas seguintes etapas:

* **Solicitado** – demandas recebidas e ainda não avaliadas.
* **Pronto para Desenvolver** – itens detalhados e priorizados.
* **Em Desenvolvimento** – funcionalidades sendo implementadas.
* **Revisão** – análise do código por outro integrante.
* **Testes** – validação funcional da implementação.
* **Entregue** – funcionalidade publicada e validada.

Além disso, foi utilizada a etiqueta **Bloqueado** para identificar itens impedidos de avançar.

## Aplicação do Kanban

Foram definidos limites de **WIP (Work in Progress)** para evitar excesso de tarefas simultâneas e melhorar o fluxo de trabalho.

Durante a simulação, foram realizadas três rodadas de trabalho, nas quais foi identificado um **gargalo recorrente na etapa de Testes**.

A partir desse problema, foi realizada uma melhoria visual na organização dos itens em teste, separando o trabalho ativo dos itens que aguardavam disponibilidade do ambiente.

## Resultados

A simulação permitiu observar na prática como:

* Os limites de WIP influenciam o tempo de entrega;
* Gargalos podem gerar filas e aumentar o cycle time;
* A priorização ajuda a tratar demandas urgentes e com prazo definido;
* A visualização do fluxo facilita a identificação de problemas;
* Melhorias contínuas podem reduzir o tempo de espera.
